# Music Therapy Study Materials

This repository contains web-based study materials developed for a music therapy research project involving hospitalized patients.

The materials are provided as standalone HTML files and can be opened directly in a standard web browser without additional software installation.

## Files

### `pre-op-EN.html`
English-language pre-intervention assessment for the preoperative setting.

### `pre-EN.html`
English-language pre-intervention assessment used before the music therapy session.

### `post-EN.html`
English-language post-intervention assessment used after the music therapy session.

## Intended Use

These materials were developed for research and clinical data collection related to music therapy in hospital settings.

They are intended to support standardized administration of brief assessments before and after a music therapy intervention.

Users should review the materials and adapt their use according to the requirements of their own clinical setting, research protocol, ethical approval, and institutional policies.

## How to Use

1. Download or open the relevant HTML file.
2. Open the file using a standard web browser.
3. Complete the assessment according to the corresponding stage of the study:
   - `pre-op-EN.html`: preoperative assessment
   - `pre-EN.html`: pre-intervention assessment
   - `post-EN.html`: post-intervention assessment
